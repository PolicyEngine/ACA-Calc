Add `/api/calculate-at-income`, which calculates each scenario for a household at one level of earnings, with what covers each member (Medicaid, CHIP, or Medicaid's work requirement keeping them off it) and, in the coverage gap, what a plan would cost without a credit. `/api/calculate` also returns the credit's income (`magi`) at each point. The API builds H.R. 1834's version of the model once per process, so a calculation under it takes under a second instead of about ten.
